Beautiful for users, safe for administrators

This module improves speed without bypassing Odoo security. Users only see what they already have access to in the backend. That makes the module practical for day-to-day teams, not only administrators.

  • Visible menus stay aligned with existing Odoo menu visibility.
  • Record search respects user read access and model permissions.
  • Actions are surfaced from what users can already reach in the interface.
  • Works as a productivity layer on top of your current security structure.
