AI Base

Common AI foundation for Odoo integrations.

AI Base provides the shared models, routing, helper configuration, and server action flow needed to build reusable AI features in Odoo. Provider-specific modules such as OpenAI can plug into this base without duplicating business logic.

Main Features

  • AI Providers: Manage reusable provider records for OpenAI and future integrations.
  • AI Types: Define business-oriented AI capabilities such as text, image, and more.
  • AI Models: Store normalized provider model records in a shared registry.
  • AI Routing: Choose which provider and model should be used for each AI type and company.
  • AI Helpers: Create reusable prompt configurations with source fields and target fields.
  • Automation Ready: Use AI Helper server actions inside Odoo automations and workflows.

Typical Workflow

  • Create AI Types and sync provider models from a provider module.
  • Configure AI Routing in Settings for each company.
  • Create AI Helpers with source fields, prompt template, and target field.
  • Use the AI Helper server action in Odoo automations.
