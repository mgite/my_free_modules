Session Replay

Capture browser replay data before errors and inspect it inside Odoo.

Session Replay stores raw replay payloads sent from the browser and makes them available for technical review inside Odoo. It is designed to help understand what happened right before a user-facing failure.

Main Features

  • Error Buffer: Keep a rolling client-side capture window before errors occur.
  • Replay Payload Storage: Save raw session replay JSON in a dedicated backend model.
  • Technical Review: Inspect captured replay records directly from Odoo views.
  • Automation Ready: Works with automation flows for post-processing and AI analysis.

Typical Workflow

  • Set the replay buffer duration in Settings.
  • Configure setting in AI Helpers menu above odoos automation rules.
  • Set target field to where should ai write response, choose source fields for context and enter your own prompt.
  • In automation rules, for actions choose "AI Helper" then fill type and ai provider, target field will autofill from chosen.
  • Let the browser capture activity before an error happens.
  • Review saved replay records from the backend.
  • Use automations to enrich analyzing captures if needed.
